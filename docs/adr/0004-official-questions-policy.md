# 官方試題與其變體只留本機自用，不公開、不販售；評鑑主題使用須標示來源

2026-11-05 iPAS（經濟部產業人才能力鑑定）以書面回覆本站的授權詢問。大意（轉述，非原文）：

1. 已公布的「評鑑內容」與「學習指引」可以參考，用來規劃學習架構、範圍、科目與評鑑主題；但須註明版本與適用性，並在適當處標示來源為「經濟部產業人才能力鑑定（iPAS）官網」。
2. 官方範例試題與已公布的考試試題僅供個人學習與教學使用，不得重製、改作，也不得用於付費題庫或商業 App；iPAS 不提供商業授權。

本站是收費網站（ADR 0001、0003），所以第 2 點等於官方試題不能進入本站題庫。

## 決定

- **官方試題與其變體只留本機**：官方試題放 `data/official/`（已列入 `.gitignore`），供擁有者個人備考。依官方題改寫的變體題（id 以 `-V<n>` 結尾，由 `tools/generate --variants` 產生）算「改作」，同樣不得公開或販售。兩者都不得進入 `data/questions/`（該目錄會提交並部署）。
- **取消「公開區分官方題／原創題」的計畫**：先前想在網站上開放官方歷屆試題並與原創題分開顯示，不再進行。
- **評鑑主題與學習範圍的使用須標示來源**：頁尾與服務條款註明「經濟部產業人才能力鑑定（iPAS）官網」公告之評鑑內容，只對已核對的初級標示版本（115 年度簡章 0410 版），並註明「以官方最新公告為準」。中級評鑑內容所依據的版本尚未核對，核對後再補進標示（見 HANDOFF 待辦）；日後改依新版評鑑內容時同步更新版本。

## 實作

- `src/lib/publicBank.test.ts`：`data/questions/*.json` 出現 `source: "official"` 或 id 符合 `-V<n>` 的題目就失敗。
- `tools/generate --variants` 的輸出改寫到 `data/official/variants/`（git 忽略）；`runVariants` 也會拒絕寫入名為 `questions` 的目錄。
- 部署路徑：`INCLUDE_OFFICIAL=1` 仍可用於本機自用建置，但不得部署。`npm run deploy`／`deploy:app` 以 `env -u INCLUDE_OFFICIAL` 建置後執行 `npm run check:dist`（`src/lib/distCheck.ts`），dist 含官方題或 `-V<n>` 變體題就中止；兩份 wrangler 設定的 `build.command` 也會跑同一檢查，所以直接 `wrangler deploy` 同樣被擋。CI 環境下 `INCLUDE_OFFICIAL=1` 的建置會直接報錯。
- `src/layouts/Base.astro` 頁尾與 `src/pages/terms.astro` 加上來源標示，由 `src/lib/legal.test.ts` 檢查。

## 未決（待擁有者決定）

出題工具的校準步驟（`tools/generate/src/exemplars.ts`、`prompt.ts`）會把官方題當作難度與寫法的範例放進給模型的提示，產出的是原創題並進入公開的收費題庫。iPAS 的回覆禁止的是重製與改作官方題，沒有明講「以官方題作風格範例產生新題」是否算改作；是否可接受，由擁有者決定。在決定前，現行程式碼不變；中級題庫目前沒有官方題或變體（見上述測試），初級尚未匯入官方題，本來就不校準。

## Considered Options

- **公開官方題並與原創題分開顯示**（原計畫）：iPAS 明確不給商業授權，而本站收費，故不採用。
- **只公開變體題**：變體是依官方題改寫，屬改作，不採用。
- **把官方題與變體放在登入後才能看的付費區**：仍是付費題庫，同樣不允許。

## Consequences

- 網站上的「題目來源」篩選（官方歷屆試題／原創模擬題）在公開題庫沒有官方題時不會出現官方選項；該功能是否移除另議。
- 擁有者仍可在本機匯入官方題、產生變體題做個人練習，這些檔案不會提交。
- `HANDOFF.md` 中「匯入官方題後校準初級出題」「開放初級變體」的待辦改為僅限本機自用，且受上面的未決事項影響。
